還沒綁定 Meegle

批量工具會用你自己的 Meegle 身分開單、評論、改狀態。綁定一次就好，大約 1 分鐘。

1複製 Token

在 Lark 開啟 Meegle → 首頁「MCP & CLI」卡片 → MCP 設定 → HTTP Header 分頁 → 按「複製 Token」

2貼到個人帳號

按下面「前往綁定」，貼上 Token 後按「綁定」。Token 會加密保存，畫面不會再顯示。

3回到這裡

綁定成功後回到這一頁，按「我綁好了，重新檢查」就能開始用。

Token 等同你的 Meegle 身分，不要貼到聊天室。
綁定失效時：同一張卡，只換標題與說明

Meegle 綁定已失效

你的 Token 已經不能用了（可能在 Meegle 按過「重置 Token」）。步驟跟綁定一樣：到 Meegle 複製新的 Token、貼到個人帳號更新，其他設定都會保留。
