開始之前

兩件事做一次就好。

綁定自己的 Meegle

工具會用你本人的 Meegle 身分開單、評論、改狀態，所以第一次要把 Meegle 的 Token 貼進來。

側欄›個人帳號›Meegle 綁定
  • 在 Lark 開啟 Meegle，首頁「MCP & CLI」卡片 → MCP 設定
  • 切到 HTTP Header 分頁，按「複製 Token」，貼到個人帳號頁的 Meegle 綁定
  • Token 等同你的 Meegle 身分，不要貼到聊天室。本站加密保存，綁定後不會再顯示
沒綁定時打開批量工具，頁面會直接出現「還沒綁定 Meegle」的提示卡，按「前往綁定 →」就會帶你過去。

準備 Lark Sheet

工具用欄名找欄位，欄名要一字不差（前後多一個空白也對不到）。每個工具需要的欄位寫在各自那一節；做完會在 Sheet 上自動加這幾欄（沒有就加在最右邊）：

回寫欄內容
Meegle 單號#單號（可點連結）。評論、狀態、修改都靠這欄認單
處理階段做到哪：已開單（Meegle）／添加評論／已切換狀態／已修改欄位
處理時間寫回的時間
單子標題貼這開單時寫「#單號＋任務名稱」；已經有別張單就不覆蓋

入口在哪

側欄›Meegle 批量工具（修仙版叫「卷宗管理」）›上方分頁
空間「Meegle 空間：測試／正式」那條只有管理員看得到。一般帳號一律送到正式空間，不用選。

開單

Sheet 每一列開成一張 Meegle 任務項，開完把單號寫回 Sheet。

01讀取 Sheet

貼上 Sheet 網址（網址要帶 ?sheet= 指定工作表）→ 按「讀取 Sheet」。「開單後推到」選了狀態，開完會接著推過去；不選就停在初始狀態。

02人員對照

Sheet 上寫的是暱稱（Aaron、Tim），要對到 Meegle 帳號。工具會自動猜，建議只是預填，要按「驗證」或「全部確認」才會記住；對照一次以後都會記得。找不到的人直接輸入 email。

03預覽與勾選

每一列會寫出能不能送、為什麼被擋。剛讀進來通常整片被擋，因為還沒指定關聯需求跟任務類型：

批量設定：先勾要開的列 → 按「批量設定」→ 選關聯需求、任務類型（也能設人員、優先順序、時間、Gitlab 等其他欄位，用右上「＋ 新增欄位」挑）→「套用到已勾選的列」。留空的不會改。

AI 產生任務名稱（選用）：選「內容欄」給 AI 讀，可勾「前綴欄」組成 [值1][值2]，面板會用第一個勾選的列顯示範例。產生後可以在表格直接改，「還原」回到 Sheet 原本的摘要。

設定好之後那幾列會變「可送出」，按右下「送出 N 列」：

04送出結果

每一列顯示單號、開單、推狀態、回寫 Sheet 的結果，可以「匯出結果」。回寫失敗的列會有「補寫回」按鈕。

評論

對 Sheet 上已有單號的單，整理「測試說明」並發一則評論，圖片、影片一起帶上去。

Meegle 批量工具›Meegle 評論
Sheet 欄名用途
Meegle 單號必填格子第一個字要是 #數字（開單會自動回填）
評論內容欄必填② 選哪一欄當內容（例如「備註」）
附件欄選填欄名有「附件」或「截圖」會自動選上；圖片嵌進測試說明，影片放成連結
填寫人欄選填用那個人的身分送（對方要綁定 Meegle、你要有代理授權）；沒有就用你自己
處理階段選填空白或「已開單…」的列預設勾選

每個欄位各自選四種之一：不修改／讀 Sheet 某一欄／固定值／明確清空。

補回填

Meegle 那邊已經完成、但 Sheet 沒寫回去的列，在這裡補。

Meegle 批量工具›Meegle 補回填
待補清單上面那塊。回寫失敗或卡住的列會自動出現，依 Sheet 分組；勾選後按「補寫回」。自己手動處理好的可以「移出清單」。
Sheet 上被清掉的回填下面那塊。回寫成功過、但後來 Sheet 上的單號／處理階段被刪掉的列。貼網址按「掃描」，勾要補的列按「補回」。

常見狀況

看到怎麼辦
還沒綁定 Meegle／綁定已失效到個人帳號重新貼 Token（在 Meegle 按過「重置 Token」舊的就失效）
被擋：沒有關聯需求／任務類型③ 勾那幾列 → 批量設定選好 → 套用；或在 Sheet 補欄位後重新讀取
警告：某某未對照回 ② 對照那個名字，或不管它（那個角色會留空）
已開過同一份 Sheet、同一列已經開過單，不會重開
回寫失敗：列已變動Sheet 插列或刪列了，工具找不到原本那列，所以沒寫。確認 Sheet 後到「補回填」補
重複單號同一張單出現在兩列，先修 Sheet
讀不到某一欄欄名要一字不差，檢查前後空白與全形半形
