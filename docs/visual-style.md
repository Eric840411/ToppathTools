## 適用範圍

除非使用者明確指定其他風格，**所有 Toppath tools 的 UI mockup、生圖、icon、設計稿都必須先套用本節**——這是預設行為，不是可選參考資料。目前正式套用範圍：AutoSpin比對工具（三路對帳）與其後續延伸功能；其他既有工具頁面不強制套用仙俠版，除非另有決策記錄。

## 兩套版本

### 普通版
現行操作型UI風格：清楚、密度高、狀態燈明確。這是監控/除錯/對帳工具的主版，資訊結構優先於視覺實驗，不套用仙俠術語/裝飾。

### 仙俠版
定位是「主題皮膚」，欄位群組/多線程機台/即時比對/不符明細等**資訊結構不變**，只換視覺語言。

**色票（青玉+墨黑+金符）：**

| 用途 | 色碼 | 說明 |
|---|---|---|
| 底色 | `#101716` | 深墨黑 |
| 底色 | `#18312F` | 黛青 |
| 主色 | `#62C6A5` | 青玉綠 |
| 輔色 | `#D8B45A` | 符金 |
| 警示 | `#D94A3A` | 朱砂紅 |
| 異常 | `#8E6BE8` | 幽紫 |
| 成功 | `#7FF0B8` | 靈玉亮綠 |

**視覺語言套用方式：**
- 區塊容器 → 玉簡、卷軸、陣盤
- 分組標題 → 符籙封條、篆文銘牌
- 狀態燈 → 靈石、魂燈、命燈
- 同步中 → 陣法運轉、靈流匯聚
- 比對成功 → 三脈歸一、靈契吻合
- 資料不符 → 靈紋錯位、陣眼偏移
- 斷線/錯誤 → 靈脈中斷、符陣破損
- 等待資料 → 玉簡未啟、靈息未至

**按鈕/標籤術語：**

| 功能 | 仙俠版術語 |
|---|---|
| 開始比對 | 啟陣 |
| 停止 | 收陣 |
| 重新整理 | 重整靈息 |
| 匯出 | 封存玉簡 |
| 詳細資料 | 展開卷宗 |
| 異常明細 | 異象錄 |
| 機台狀態 | 靈脈狀態 |
| 三路對帳 | 三脈校驗 |

**裝飾克制原則**：邊框可用細金線、角落加小型符紋、狀態點做成發光靈石；**不要**大面積雲霧/山水/人物插畫，會干擾監控工具的掃讀效率。整體感覺是「修真門派的高密度監控陣盤」，不是RPG背包UI。

## 禁忌

- **一律禁用原生emoji圖片**（畫面上的icon改用lucide/icon asset/文字符號，不要用系統原生emoji渲染）
- 仙俠版裝飾不要大面積雲霧/山水/人物插畫
- 語意色（警示橘/錯誤紅/成功綠/disabled/hover/focus/選中tab/日誌高亮）不等於主色系——仙俠版配色如果跟語意色打架，優先只調整衝突的語意token，不要整套底色重改（2026-08-10 CodeX建議）

## 檢查重點（換版本/新頁面時至少截圖這幾處）

- 三路對帳主tab
- 盒子日誌警示列
- 資料為空/載入中狀態
- 按鈕hover或active
- 深色底上小字對比
