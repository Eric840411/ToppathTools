# 多 TC 錄製脚本

入口：UAT 後台工作台 → TC 清單 → **多 TC 錄製腳本**。

1. 在主畫面貼上 Lark Bitable 網址並掃描。進入多 TC 工作台，填腳本名称，勾選各筆 TC。相同編號的不同描述可同時綁定，系統使用各列的 recordId 區分。
2. 按「錄製並接在後面」。在 Local Agent 開啟的後台視窗，從右下角「檢查與截圖歸屬」選 TC。一般操作預設共用；檢查、讀值與截圖會歸入選定 TC。可切換回先前的 TC，繼續加入更新後的檢查與圖片。
3. 用標記模式點欄位，新增有值、數值相等、文字相等等檢查。截圖按鈕保存整個可見畫面；標記選單中的「截取這個區域」保存選定元素。每筆可有多張圖片。暫停可處理無關操作；停止會保存目前輸入欄位的最後值。
4. 停止後檢查左側「各 TC 對照」。右側可調整每步歸屬、順序、參數或刪除，亦可新增「等待更新」共用步驟。同一筆 TC 可出現在不同時間點。刪除步驟不會撤銷實際後台操作。
5. 儲存並試跑，確認結果後再選「正式執行並回寫 Lark」。試跑仍會操作後台，但不會上傳或回寫。正式執行需確認要更新的 TC 數量，並以當次圖片取代各筆附圖。

## 結果

- PASS：有效檢查通過，且沒有失敗、警告或需人工結果。
- FAIL：該 TC 的硬失敗；保留已取得圖片，並嘗試擷取失敗點，其他獨立 TC 繼續。
- 未驗證：沒有成功執行的檢查，或有警告／人工判讀。只截圖不算驗證。
- 受阻：共用前置操作失敗或執行中止。
- 正式回寫的未驗證／受阻清除 PASS 與 FAIL 勾選。使用者中止則不回寫；畫面保留「未回寫」標示。
- 圖片上傳失敗會保留該筆原有 Lark 附件，並顯示未回寫。驗證判定與回寫成功是分開的狀態。

## 使用前更新

此版本有新增 API 與 Agent 執行模組。建置後須重啟工具的 server／worker，Local Agent 按「更新程式碼」後重啟，再刷新頁面。舊 Agent 會被更新檢查擋下。

錄製腳本保存於伺服器資料庫，按登入者分開；每輪結果另存當次腳本快照。先以測試環境驗證實際 selector 和期望值，不要把當下畫面值直接視為正確規格。


## v4.138.0 編輯與除錯

- 每步可拖曳排序（也保留上移／下移）、複製或停用。停用項目仍保留在腳本，執行時跳過且不計入有效檢查。複製讀值步驟會產生新的變數名，後續斷言如需使用新讀值，請調整引用。
- 點選步驟後勾「插入選取步驟之後」，新增積木會放在該位置；「補錄至第 N 步後」會將新錄製片段插入該處，不刪除原片段。補錄會開啟新的錄製視窗，不會自動重播前置操作；先暫停並自行操作到需要補錄的畫面，再繼續。
- 「從頭試跑至第 N 步」沿用前置操作與變數，執行到選定位置即結束；不會寫入 Lark，且不把局部成功當成整筆 TC 的 PASS。完整正式執行仍走原本的確認流程。
- 最近結果的「逐步診斷與證據」可看定位命中數、可見性、座標、金框元素預覽、文字／數值斷言的預期與實際值、每步耗時、失敗點圖片。共用步驟診斷集中於第一筆 TC，避免重複傳送。舊結果需重新執行才有逐步資料。
- 圖片預覽最大 480 × 300，整輪預覽限制約 4 MB；超出容量或圖檔太大時保留原圖路徑。Lark 附件仍使用原始截圖，不使用縮圖。

## 區域圖片比對

新增「區域圖片比對」積木，指定唯一的元素 selector，並上傳人工確認過的區域 PNG 基準圖。支援調整容許差異百分比（0～100）與每像素色差容差（0～255）。圖片尺寸必須一致；缺圖、圖片格式不符、尺寸不同均不能通過。像素比對會保存當次圖片與差異圖，並歸屬所選 TC。動態金額、時間或動畫請選擇穩定區域，或改用文字／數值斷言。

單張 PNG 最多 2 MB／400 萬像素，整份腳本含基準圖最多 8 MB。基準圖不會因試跑失敗而自動更新。

更新後需重啟 server／worker，Local Agent 更新程式碼後重啟。既有獨立 Agent 若尚未安裝圖片套件，需在該 Agent 目錄執行 `npm install pngjs@7`；新版安裝包已包含此依賴。缺套件時區域比對會明確報錯，其他既有操作不受此依賴影響。


## v4.139.0 伺服器桌面錄製

主畫面的執行位置明確選「伺服器」時，一般與多 TC 錄製會直接在伺服器開啟 Chromium，無須啟動 Agent。請在伺服器本機或可操作該桌面的遠端桌面工作階段錄製；只透過其他電腦的網頁連入並不會讓錄製視窗出現在那台電腦。自動選擇或指定 Agent 模式仍使用 Agent，不會默默回退。伺服器同時只接受一個錄製視窗，停止或關窗後可開始下一輪，最長 30 分鐘自動收尾。登入成功後才開始收事件，帳密不會被錄入步驟。


## 人工指定 Lark 判定

在新增積木選「回填 Lark PASS／FAIL」，指定 TC，展開步驟選 PASS 或 FAIL 並填寫判定說明。每筆 TC 只能有一個啟用的指定判定。這是腳本作者的人工指定，不是系統自動驗證畫面正確。只有正式執行會回寫；試跑只顯示預計結果。實際執行失敗仍為 FAIL，共用前置失敗仍受阻，人工 PASS 不能覆蓋。建議放在該 TC 截圖後，原有的截圖與逐筆附件回寫不變。


## 錄製腳本主入口（4.141.0）

主清單顯示登入者已儲存的錄製腳本，可依名稱或綁定 TC 搜尋。點選直接開啟編輯與結果；新增一律開啟空白腳本，關閉後重新整理清單。主入口不再啟動舊版全表批次測試。

舊版逐筆 TC、預設驗證器、積木匯入匯出與靜態覆蓋率仍供既有測試使用，集中在「舊版 TC 模式」。錄製腳本仍使用積木引擎執行操作、讀值、檢查與截圖，因此不刪除引擎或已有測試資料。
