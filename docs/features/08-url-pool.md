## 8. OSM Tools — URL 帳號池（UrlPoolPage）

**路由**：`/api/url-pool/*`

### 功能說明
管理多個帳號的大廳 URL，自動分配給測試任務使用，避免帳號衝突。

### 使用者操作
| 操作 | 說明 |
|------|------|
| 查看帳號池狀態 | 顯示各帳號目前使用狀態（空閒/佔用）|
| Claim / Release URL | 手動佔用或釋放帳號 |
| 設定覆蓋值 | 暫時覆蓋某帳號的 URL |
| 直接跳轉 | 以指定帳號跳轉到對應大廳 URL |
| 監聽狀態變更 | SSE 即時通知帳號池狀態變更 |
